How the AI connection works

GitHub Pages is static hosting, so this page cannot safely hold a private API secret on a server. Instead, you supply your own Pollinations key in the sidebar. It is held only in this browser tab's session storage, and requests go directly to https://gen.pollinations.ai/v1/chat/completions. No key is included in the public source code. Model availability and account pricing are controlled by the provider.
